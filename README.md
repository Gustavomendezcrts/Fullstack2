# Fullstack2

## Orden

Cada clase donde tenemos tareas o ejemplos que sean necesarios entenderlos o guardarlos
los guardare en este rositorio con este formato de carpeta:

```text
DD-MM-YYYY %nombre pagina%
```

Ejemplo:

```text
13-08-2026 Mascotienda/
├── index.html
├── style.css
└── ...
```
